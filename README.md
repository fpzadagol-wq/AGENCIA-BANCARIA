# Agência Bancária

Sistema demonstrativo de gerenciamento e atendimento bancário, desenvolvido em HTML, CSS e JavaScript puro.

## Funcionalidades
- Painel com indicadores de clientes e atendimentos
- Cadastro de clientes fictícios
- Geração de protocolos de atendimento
- Histórico de atendimentos
- Pesquisa de clientes no painel administrativo

## Como executar
Abra o arquivo `index.html` no navegador.

## Dados
Os registros são armazenados no `localStorage` do navegador. Esta aplicação é apenas demonstrativa: não realiza operações bancárias reais e não possui autenticação ou armazenamento compartilhado entre usuários.

## Publicação
O site é publicado pelo GitHub Pages por meio do workflow em `.github/workflows/pages.yml`.
